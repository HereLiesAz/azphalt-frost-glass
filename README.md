# Frost Glass

Diffuses the frame through frosted glass — a soft, privacy-glass scatter that keeps colour but dissolves detail.

An [azphalt](https://github.com/HereLiesAz/azphalt) extension for
[Guillotine](https://github.com/HereLiesAz/Guillotine).

- **Package id** — `com.hereliesaz.azphalt.frost-glass`
- **Version** — 1.0.0
- **Kind** — asset (ISF fragment shader)
- **Tags** — `shader`, `distortion`, `frost`, `glass`, `diffusion`, `soft-focus`, `one-click`

## Controls

| Parameter | Label | Range | Default |
| --- | --- | --- | --- |
| `frost` | Frost | 0.0 – 1.0 | 0.5 |
| `drift` | Drift | 0.0 – 1.0 | 0.25 |

## Install

Open **Azphalt Store** inside Guillotine, find *Frost Glass*, and tap **Install**. The effect is
applied to the selected clip.

To install manually, pack this directory as a `.azp` (a plain ZIP with `manifest.json` at the root)
and side-load it from the store's *Install from file* action.
